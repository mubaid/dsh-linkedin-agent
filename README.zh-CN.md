# dsh-linkedin-agent

**DeepSeek Harness 中的十一个 LinkedIn agent 技能** — 用 21 种钩子公式发帖、评论他人帖子、回复自己的帖子、100 分档案评分、周计划，以及发帖前剥离 AI 指纹的人类化器。免费、MIT、无需注册。

[English](./README.md) | [简体中文](./README.zh-CN.md)

安装：

```bash
dsh plugin add github:mubaid/dsh-linkedin-agent
```
